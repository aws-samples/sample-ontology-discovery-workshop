# Ontology Discovery Workflow

업무를 설명하고, 관련 자료를 확인하면서 그래프 모델을 만드는 워크숍입니다. 참가자는 평소 쓰는 로컬 AI 도구와 대화합니다. AI는 업무에 등장하는 대상과 관계를 정리하고, 참가자는 웹에서 그래프를 보며 모델을 검토합니다.

## 역할

로컬 AI는 질문을 만들고 답변을 바탕으로 모델을 작성합니다. DB 스키마, API 명세, 모델 코드를 참고하고 사용자 결정에 따라 엔티티와 관계를 수정합니다. Claude Code, Kiro CLI, Codex에서 사용할 수 있습니다.

로컬 웹은 모델을 확인하는 화면입니다. 타입과 인스턴스를 나눠 보고, 속성과 근거를 확인하고, Cypher로 업무 질문을 조회합니다. 수정할 내용은 로컬 AI에 전달합니다.

## 진행 순서

| 단계 | 하는 일 |
|---|---|
| 자료 확인 | 프로젝트에 있는 스키마와 문서를 찾습니다. |
| 범위 설정 | 다룰 업무, 참여자, 목적을 정합니다. |
| 데이터 조사 | 현재 데이터에서 엔티티와 관계 후보를 정리합니다. |
| 업무 설명 | 누가 어떤 일을 하고 무엇을 주고받는지 기록합니다. |
| 이벤트 정리 | 발생한 일과 이를 일으킨 명령, 정책을 정리합니다. |
| 모델 작성 | 엔티티, 관계, 속성, 식별자를 검토하고 그래프 모델로 묶습니다. |

각 단계는 사용자가 확인한 뒤 넘어갑니다. 중간에 멈췄다면 저장한 상태와 답변을 읽고 이어서 진행합니다.

## 웹 화면

- 왼쪽에서 Cypher를 실행하고 결과, 실행 이력, 모델 변경 전후를 확인합니다.
- 가운데에서 T-box와 A-box를 전환하고 그래프를 탐색합니다.
- 오른쪽에서 엔티티 타입, 관계 타입, 노드 속성, 그래프 품질 경고를 확인합니다.

T-box는 타입과 관계의 정의입니다. A-box는 그 정의에 따른 인스턴스입니다. 품질 검사는 고립된 노드, 누락된 식별자, 잘못된 타입이나 연결을 찾아 검토할 항목으로 보여줍니다.

## 결과물

| 결과물 | 내용 |
|---|---|
| 온톨로지 문서 | 업무 용어, 엔티티, 관계, 결정 근거 |
| 모델 JSON | T-box, A-box, 속성, 추적 정보 |
| 스키마 Cypher | 노드 타입, 관계 타입, 속성 타입, 기본 키 정의 |
| 데이터 Cypher | 인스턴스와 관계를 생성하는 문장 |
| 전체 모델 Cypher | 스키마와 데이터를 함께 생성하는 문장 |
| 변경 이력 | 모델을 수정한 사람, 이유, 변경 전후 |
| 그래프 이미지 | PNG 또는 SVG |

Cypher는 그래프를 조회하고 정의하는 언어입니다. 워크숍에서 만든 스키마와 데이터는 웹의 내보내기 메뉴에서 `.cypher` 파일로 저장할 수 있습니다.

## 시작하기

설치 후 로컬 AI 도구에 `온톨로지 발견 시작`이라고 입력합니다. Claude Code에서는 `/onto-discover` 명령도 사용할 수 있습니다.

- 설치와 실행: [로컬 웹 사용법](../viz-server/README.md)
- 진행 규칙: [워크숍 규칙](../ontology-rules/core-workflow.md)
- 예제: [결제 정산 워크숍](../examples/payment-settlement/README.md)

규칙과 산출물은 프로젝트 파일로 저장합니다. 원본 자료는 읽기 전용으로 사용합니다.
