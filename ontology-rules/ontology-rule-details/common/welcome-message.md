# 시작 안내

`ontology-state.md`가 없을 때 다음 메시지를 한 번 출력한다. 기존 상태가 있으면 `session-continuity.md`의 재개 절차를 따른다.

## 안내 문구

```text
Ontology Discovery Workflow

업무를 설명하고 관련 자료를 확인하면서 그래프 모델을 만듭니다.
모델 작성은 로컬 AI에서 진행하고, 브라우저에서 결과를 검토합니다.

진행 순서:
1. 프로젝트 자료 확인
2. 목적과 범위 설정
3. 데이터 구조 조사
4. 업무 시나리오 작성
5. 이벤트와 관계 정리
6. 온톨로지 모델 작성

질문은 채팅 또는 질문 파일로 답합니다. 각 단계는 사용자가 확인한 뒤 넘어갑니다.
산출물과 답변은 ontology-docs/에 저장합니다. 스키마와 인스턴스는 Cypher로 내보낼 수 있습니다.
원본 자료는 읽기 전용으로 사용하고, 업무 용어는 사용자 확인을 거칩니다.

프로젝트 자료 확인부터 시작할까요? (Yes / No)
```

## 응답 처리

- Yes: Phase 0을 시작하고 상태 파일을 만든다.
- No: 상태 파일을 만들지 않고 종료한다.
- 질문: 답변한 뒤 시작 여부를 다시 묻는다.

사용자가 시작 안내를 건너뛰도록 요청했거나 이미 안내했다면 반복하지 않는다. 사용자의 언어로 안내하되 내부 파일명과 필드명은 유지한다.
