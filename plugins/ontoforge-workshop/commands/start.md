Use the `run-workshop` skill to inspect the repository runtime, start or reuse the
loopback server, and facilitate only the current OntoForge stage. Prefer the current
stage Markdown form when the repository provides one. Do not print a full multi-field
questionnaire in the CLI and do not reset an existing session without explicit user
approval.
